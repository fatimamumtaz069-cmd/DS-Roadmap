The 8 steps

Tick each step when you finish it. Times are only suggestions and depend on how much you practise each day.

Common mistakes

Only watching tutorials

Write code yourself after every lesson. Practice is where learning happens.

Skipping the maths

Basic statistics helps you understand why a model works, not only how to run it.

Jumping to deep learning

Master data cleaning and classic machine learning first. They are used far more often.

No projects online

Put your work on GitHub and write about it. Others cannot see what stays on your laptop.

Free places to learn

Kaggle Learn

Short hands-on courses on Python, pandas, SQL and machine learning.

Google Colab

Run Python in your browser with no setup.

pandas docs

The official guide for data analysis in Python.

scikit-learn
